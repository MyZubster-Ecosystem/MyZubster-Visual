# MyZubster Comic Contributors

This directory tracks real public contributor aliases that are allowed to appear as canonical participants in the comic universe.

## Admission rule

A contributor may be listed as a real MyZubster contributor only when a canonical public record supports the claim. If a MYZ reward is mentioned, the reward record must also exist; do not infer payment from GitHub activity alone.

## Contributor card fields

- public alias;
- contribution type;
- supporting repository/issue/record;
- optional verified MYZ reward record;
- consent/publicity status where applicable;
- comic character status;
- first appearance.

Unverified aliases belong in concept art only and must be marked `CONCEPT_ONLY`.
