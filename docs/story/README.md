Canonical story-production workspace for the MyZubster cyberpunk comic universe.

## Canon rule

Real-life claims must be supported by source material or explicitly marked `UNVERIFIED_SOURCE_NEEDED`.

Cyberpunk scenes may fictionalize the presentation, but they must not turn fictional blockchain, payment, reward, infrastructure or contributor status into claims about the real platform.

## Evidence rule

When an episode references a real photograph or observation, link to the canonical public-safe asset and metadata rather than duplicating raw/private source files.

Recommended chain:

```text
REAL EVENT / DISCOVERY
 -> PUBLIC-SAFE PHOTO OR ARTIFACT
 -> SHA-256 / METADATA
 -> OBSERVATION / STORY CARD
 -> CYBERPUNK ADAPTATION
 -> EPISODE
```

## Rewards

MYZ is an internal MyZubster reward/accounting ledger. A story, image, issue, merge or publication does not by itself prove a reward or external payment. XMR/token settlement is separate and requires independent verification.
