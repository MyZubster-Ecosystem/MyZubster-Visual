# Daniel // MyZubster: Origins

Status: `PLANNED`

The first autobiographical cyberpunk saga. Episodes are drafted from verified project history plus Daniel's future first-person biography inputs.

## Episode roadmap

1. **Before the Network** — life before the MyZubster system; biography source required.
2. **The First Signal** — the ideas and real-world observations that begin to connect.
3. **Builders' Solitude** — real constraints, setbacks and persistence; source-backed only.
4. **Archive of Proof** — public-safe photos, SHA-256, metadata, provenance and observations become story artifacts.
5. **Birth of the Bots** — verified bot/agent projects are introduced as cyberpunk characters while preserving the difference between fiction and deployed capabilities.
6. **Decentralized Memory** — GitHub/IPFS/evidence architecture becomes part of the narrative where supported by canonical project records.

## Episode definition of done

Each episode should include:

- story synopsis;
- real-life source notes;
- fiction disclosure;
- scene list;
- character list;
- linked public-safe photo/evidence references;
- linked metadata/provenance references;
- visual assets;
- privacy review where real people or places appear;
- technical-claim QA;
- publication status.
